# Khaos's Multiverse

A self-contained, Loki-inspired Discord portal website featuring a glowing cosmic tree and three clickable realms.

## Realm links

- **Yggdrasil** (green): https://discord.gg/NuPMs8zerA
- **Pleasure Planet** (pink): https://discord.gg/bXXxS3W4Y3
- **The Umbral Sanctuary** (purple): https://discord.gg/V7u4RXrtK7

## Deploy to Vercel

1. Upload `index.html`, `styles.css`, and `script.js` to the root of the GitHub repository `Khaoskami/Khaos-s-multiverse-`.
2. Visit https://vercel.com/new and choose **Import Git Repository**.
3. Select `Khaos-s-multiverse-`.
4. Choose **Other** as the framework preset, leave the Build Command empty, and use `.` as the output directory (if prompted).
5. Click **Deploy**. Future commits to the connected branch trigger new deployments.

No API keys, npm installation, build tools, or environment variables are required. The site uses Google Fonts, with serif/sans-serif fallbacks if unavailable.

## Edit invite links

Search for the Discord invite URL in `index.html` and replace each instance (the planet and card links).
